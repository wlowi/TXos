
Communication Protocol
======================

Serial line parameters
----------------------
57600 Bd, N81


When Import/Export module on the transmitter is enabled it sends 
the info block. Currently this contains only the transmitter software version.

Example:
--------
{IN
VN"6:0.5.19
}60475


Communiation blocks
-------------------
GS - Get system config
GM - Get model config
IN - Info block
ER - Error block
OK - Success block
MC - Model config answer
SC - System config answer
